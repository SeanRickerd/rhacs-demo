= Advanced Cluster Security Demo

== Overview

This demonstration environment showcases Red Hat Advanced Cluster Security (RHACS) {rhacs_version} -- the unified security platform for OpenShift and Kubernetes covering build, deploy, and runtime security across the full application lifecycle.

=== What's New in RHACS 5.x

This demo environment highlights the latest capabilities in RHACS {rhacs_version}:

* *Exploit Prediction Scoring System (EPSS)* -- Prioritize vulnerabilities based on real-world exploitation probability, not just severity scores. EPSS data is surfaced alongside CVSS to help teams focus remediation effort on CVEs that are both severe and likely to be exploited.

* *Init Container Security Coverage* -- Full vulnerability scanning and policy enforcement for init containers. This closes a security gap that attackers previously exploited -- init containers are now monitored with the same rigor as application containers.

* *File Activity Monitoring (FAM)* -- Real-time detection of file access, modification, and rename events in containerized workloads and on cluster nodes. FAM addresses compliance requirements for file integrity monitoring in PCI-DSS, HIPAA, and NIST frameworks.

* *OpenShift Lightspeed AI Integration* -- AI-powered risk explanations and remediation guidance using the same LLM backend as OpenShift Lightspeed. Security data is presented in plain English with specific, actionable recommendations.

* *Model Context Protocol (MCP) Integration* -- Expose RHACS security data to AI agents and assistants for conversational queries and automated workflows. Ask questions like "Which deployments have Log4Shell?" and get structured, actionable answers from your AI assistant.

* *Virtual Machine Vulnerability Scanning* -- Unified vulnerability visibility for containers AND virtual machines running on OpenShift Virtualization. Scan RHEL-based VM guest operating systems from the same console that manages container security.

=== Demo Environment Components

This lab environment includes:

* *RHACS Central* -- The security control plane with the web console and API
* *Secured Clusters* -- OpenShift clusters with RHACS sensors deployed for runtime monitoring
* *Sample Workloads* -- Deployments with various security configurations, vulnerabilities, and runtime behaviors for demonstration
* *Integrations* -- Pre-configured integrations with Splunk, MCP server, OpenShift Pipelines (Tekton), and Policy as Code via Argo CD
* *Sample Virtual Machine* -- A virtual machine workload for demonstrating VM vulnerability scanning
* *File Activity Monitoring* -- Enabled on the demo cluster to showcase runtime file integrity monitoring

== Setup Instructions

Below are the instructions to set up the demo. 

There is a single installation script called *`install-all-setup.sh`*. It runs *basic-setup* first, then runs five other setup scripts in parallel:

* FAM (file activity monitoring)
* Perses monitoring in the console
* MCP server setup
* OpenShift Pipelines (Tekton) RHACS tasks
* Policy as Code (GitOps) via Argo CD
* A Splunk instance with Violations sent to it

The lab environment includes a sample virtual machine for vulnerability-management demos; you do not need to provision or register a VM as part of this install.

=== Requirements

All requirements are configured by the *basic-setup* script and the parallel setup steps above.

=== Set up scripts

.Procedure
. Run the following command into your terminal:
+
[source,sh,subs="attributes",role=execute]
----
source ~/.bashrc
git clone https://github.com/mfosterrox/rhacs-demo.git || (cd rhacs-demo && git pull)
chmod +x install-all-setup.sh verify-all-setup.sh
./install-all-setup.sh -p {acs_portal_password}
----

. Wait until the script finishes. You should see *Phase 1* (basic-setup) complete, then *Phase 2* parallel jobs start and *Waiting for N parallel job(s)* complete without errors.

IMPORTANT: If a script fails, you can run the individual script again. The error messages will provide the command to rerun the script.

=== Verify success

Run the verification script.

[source,sh,subs="attributes",role=execute]
----
cd ~/rhacs-demo
source ~/.bashrc
./verify-all-setup.sh
----

OUTPUT:
[source,text]
----
[STEP] Summary
  ✓ No failed checks (0 warning(s))
----

WARNING: ACS Scanner v4 may take a 5-20 minutes to complete the initial scan. This is normal and expected.
